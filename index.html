Usage

Every generated font keeps the original InSales API: font family insales-icons, classes .icon-* and CSS variables --icon-code-*. Pick a stylesheet, then use the class: 

<i class="icon-cart"></i>
/* or read the codepoint from a CSS variable */
.icon-cart::before {
  content: var(--icon-code-cart);
  font-family: "insales-icons";
}

Generated with Vite + fantasticon · codepoints E800–E852 match the original InSales font-generator build · demo fonts are rebuilt on every deploy from the npm-published SVG sources.
